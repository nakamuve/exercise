# Nakamuve Strength — Exercise Library

An **Astro static site** (deployable to **Cloudflare Pages**) that turns the
1,324-exercise [exercises-dataset](https://github.com/hasaneyldrm/logpress-public/tree/main) into an
interactive training reference with a **side-mode filter**: how each exercise
is performed — **one side at a time**, **both sides together**, or **either way**.

## Why the side-mode filter matters

| Mode | What it is | Use it for |
| --- | --- | --- |
| **Each side** (unilateral) | Done one side at a time: lunges, split squats, one-arm rows, alternating work… | **Eccentric overload** — a lighter load per side lets you slow and control the lowering phase. Train **both sides in balance**: match sets × reps left and right. |
| **Both sides** (bilateral) | Done with both sides together: barbell & machine compounds, push-ups, squats, jumps… | The **biggest load** — both limbs share the bar, most efficient for maximal strength. Watch for a strong side masking a weaker one. |
| **Either way** | The same movement works one side at a time or both together: most dumbbell / kettlebell / band / cable work… | Pick the goal — each side for eccentric & balance work, both sides for max load. |

The classification (255 each-side · 633 both-sides · 436 either-way) is
generated by [`scripts/classify.py`](scripts/classify.py) from the dataset's
names, equipment and movement patterns, with manual overrides. See the
"how the side-mode tag is determined" note on the site itself.

## Features

- **Search + filters**: side-mode segmented control, category / equipment /
  target-muscle dropdowns, free-text search, sort — all shareable via URL
  query params (`?side=unilateral&q=lunge`).
- **Card grid**: thumbnail with **hover → animation GIF** swap, side-mode
  badge, target + equipment chips; infinite scroll + "load more".
- **Detail panel**: slide-over with the animation, the side-mode coaching
  rationale, numbered instructions, target & involved muscles, and
  prev/next navigation (`←`/`→`, `Esc` to close, `/` to search).
- Zero runtime dependencies, no framework JS — one small vanilla-TS bundle.
- Light, athletic design; respects `prefers-reduced-motion`.

## Local development

```bash
npm install

# 1. (once) pull the dataset media into public/ — images, videos, licenses
./scripts/copy_media.sh ../exercises-dataset

# 2. (once) regenerate the classified dataset bundle
#    expects data/exercises.json (copy of ../exercises-dataset/data/exercises.json)
mkdir -p data && cp ../exercises-dataset/data/exercises.json data/
npm run classify        # writes public/data/exercises.json

npm run dev             # http://localhost:4321
npm run check           # astro check (types)
npm run build           # static output in dist/
npm run preview         # serve dist/ locally
```

## Deploy to Cloudflare Pages

The site is fully static — no runtime, no serverless functions.

**Dashboard (recommended for first deploy)**

1. Cloudflare dashboard → Workers & Pages → Create → Pages → Connect to Git.
2. Framework preset: **Astro**; build command `npm run build`; output
   directory `dist`.
3. Deploy. Subsequent pushes to the branch rebuild automatically.

**Wrangler CLI**

```bash
npm run deploy          # = npx wrangler pages deploy dist
# or, if you created the project in the dashboard:
npx wrangler pages project create nakamuve-strength --production-branch main
```

`wrangler.toml` sets the Pages output dir; [`public/_headers`](public/_headers)
adds long-lived caching for the immutable media and short revalidation for
HTML and the dataset bundle.

> Media size note: the deploy includes ~126 MB of animation GIFs and ~12 MB of
> thumbnails. The grid still works if you drop `public/videos` (hover previews
> simply won't animate).

## Project layout

```
scripts/
  classify.py       # side-mode classification → public/data/exercises.json
  copy_media.sh     # copies images/videos/licenses from exercises-dataset
public/
  data/exercises.json   # trimmed English dataset + side tag (fetched at runtime)
  images/  videos/       # media (gitignored, regenerated)
  _headers  robots.txt  DATASET-*
src/
  pages/index.astro              # page shell (header, footer, methodology)
  components/ExerciseBrowser.astro  # island markup (hero, filters, grid, overlay)
  scripts/browser.ts             # all client interactivity
  styles/site.css                # design system
wrangler.toml                    # Cloudflare Pages config
```
